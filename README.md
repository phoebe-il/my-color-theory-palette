# My Color Theory Palette

An animated, single-page infographic built as a Claude Artifact. It maps a
personal makeup color palette for light-to-medium skin with a neutral-warm
undertone, using color theory only (no product recommendations).

## What it shows

- Skin tone: depth and undertone, named and explained
- Anchor shade: a current everyday lip color read by hue, temperature,
  saturation and value
- Goal palette: a nude look with a hint of pink, built on three rules
  (stay muted, keep the warmth, one pink accent)
- Color cards for cheeks, lips and eyes, each with a short note on why the
  color suits that part of the face
- Colors to avoid, and the color-theory reason they clash

## Design

- Light lavender background with Cinzel Decorative typography
- Colors drawn as animated paint brush strokes
- Scroll-triggered reveal animations
- Twinkling pink star field in the background
- Respects prefers-reduced-motion

## About this project

This page is a Claude Artifact: a single self-contained HTML file generated
with Claude (Anthropic) and published as a hosted page. It has no build step
and no dependencies beyond Google Fonts. Open the HTML file in a browser to
view it.

## Notes

Colors are screen approximations.
